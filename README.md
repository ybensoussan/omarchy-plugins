# omarchy-plugins

Custom Omarchy plugins and configs.

- `plugins/` -> `~/.config/omarchy/plugins/`
- `omarchy/` -> `~/.config/omarchy/` (shell, hooks, themes, extensions, branding)
- `hypr/` -> `~/.config/hypr/`

Third-party plugins (e.g. jankeesvw.notification-center) and wallpapers are not included.
